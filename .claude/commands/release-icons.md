---

Собери полный релиз ProPDA со всеми вариантами иконок и залей на GitHub.

Запусти:

```bash
scripts/release_with_icons.sh
```

Аргументы (передавай, если пользователь их указал в $ARGUMENTS):
- `--notes <файл>` — описание релиза из файла (иначе GitHub сгенерит заметки сам)
- `--variants glass_4,metal_4` — только перечисленные иконки вместо всех
- `--skip-build` — не пересобирать, использовать уже собранный APK

Важно:
- Версия берётся из `app/build.gradle` автоматически — НЕ поднимай её сам, если пользователь об этом не просил.
- Исходники НЕ пушить: релиз вешается на существующий коммит, заливаются только APK.
- Сборка идёт ключом из `keystore.parallel.properties` (ForPDA 2).
- После заливки покажи ссылку на релиз и список залитых ассетов; при ошибке — покажи, на каком шаге упало.
